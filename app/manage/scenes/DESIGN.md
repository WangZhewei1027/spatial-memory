# 场景演出编排：Three.js Editor + 多媒体时间轴

## Overview

场景编辑器在既有编排能力上扩展为浮岛式演出工作台。连续舞台承载空间内容，项目栏、素材库、原生工具、所选对象检视器和时间轴各自成为独立工作面；团队模型、图片、音频、视频与场景独有的空间文字共用选择、变换、分组和撤销模型。

这是现有场景编辑器的 Operate 模式局部扩展。全站视觉规范仍以 `docs/design-system.md` 和现有语义 token 为准；固定 Light 主题、Three.js Editor r183 原生视口及应用管理的文档、关键帧和保存流程继续保留。层级与顺序由时间轴轨道头部管理，素材库负责复用素材，检视器只编辑当前选择，不另建对象树。

## Colors

- 工作台固定使用 Light 主题。`app/globals.css` 的 `:root` 与 `.scene-workspace-theme` 共用全站浅色语义 token；局部主题加深辅助文字和错误色，保持选中浅灰背景与浅底上的可读性。后台其他页面的主题偏好独立。
- 白色工作面使用 `background`，舞台外框和次级区域使用 `muted`，边线使用 `border`，选择使用 `accent` / `secondary`。保存主操作、播放头、拖放时间提示及焦点反馈沿用 `primary` / `ring`，不增加全局品牌色。
- 模型和图片片段使用次级表面；音频、视频片段使用 `primary` 的浅色底；文字片段使用白底虚线轮廓。类型同时由轨道头部的图标和名称表达，不只依靠颜色。
- Three 原生视口保留上游 Light 背景和工具图标。应用提供均匀的 1 米网格与带 X/Y/Z 标签的原点轴，轴色遵循 Three 的空间方向约定；虚拟摄像机与视锥是编辑辅助器。用户设置的空间文字颜色属于场景内容，不改变应用 UI 配色。

## Typography

使用全站字体栈和 `Text` 组件。面板标题与说明沿用 14px 辅助字号；12px 用于素材卡片名称、类型分类、字段标签、轨道、刻度和数值等紧凑控件。不引入展示字体或营销字号。

时间与数值使用等宽数字；素材、轨道和片段名称显式截断并保留完整提示。zh/en 文案共享布局，工具栏允许横向滚动，说明文字自然换行。空间文字是可编辑的场景内容，检视器里的字号和宽度以米表示，不属于应用 UI 字号刻度。

## Layout

- `SceneEditor` 在同一 DOM 中组合独立浮岛与连续舞台。项目栏位于顶部，承载返回、素材库开关、名称、未保存状态、撤销/重做、文字、预览、保存和适用时的二维码入口。项目栏高度 48px；桌面外围留白和工作面间距统一 12px，手机为 6px。
- 工作区沿用地图编辑器的分栏岛面：素材库作为独立左列从项目栏下方延伸到底部，与右侧时间轴底边对齐；宽屏宽 352px，低于 1200px 时为 320px。顶部内容分类固定，导入、视图切换和搜索位于浏览区上方，结果填满剩余空间并独立滚动。右列纵向排列舞台与时间轴，收起素材库后两者同步扩展。选中对象后，检视器浮在舞台右侧，分别宽 284px / 260px，属性内容独立纵向滚动。舞台左上角采用 Unity 式工具覆盖层：顶部紧凑视图条依次放着色模式、问号标签开关及 Gizmos 下拉箭头、聚焦/回到原点/虚拟相机；下方左侧竖排移动/旋转/缩放。两组各有紧凑表面，不用大面板包裹；窄屏按功能组换行，问号与下拉箭头、着色优先留在同一行，桌面距顶边和左边均为 12px，手机为 8px；底部仅在网格和文字标签均开启时显示“每格 1 米”。快捷键放在对应控件的提示中。
- 小于 1024px 时，素材库默认收起，展开后覆盖整个工作区高度，宽度不超过 352px 且留出视口边距；选中轨道或舞台对象会收起素材库并显示检视器，两面板不同时叠加，检视器限制在可视宽度内。关闭面板或开关预览保留编辑会话。
- 时间轴只占右列下方，不延伸到素材库底部；默认高度 `min(38vh, 360px)`；小于 640px 时为 36vh。顶部边缘可拖动调高，也可用方向键调整；范围为 140px 至视口高度的 70%，用户高度记在本机浏览器。实际高度还受右列可用高度限制，至少为舞台保留 160px，防止旧高度设置把时间轴挤出短屏。高度不超过 560px 时仍保留素材结果区内部滚动，隐藏舞台底部辅助提示以避免遮挡。
- 时间轴工具栏与轨道区分别滚动，轨道名称列横向吸附，标尺纵向吸附。轨道头部默认宽 300px；时间轴可视宽度小于 640px 时缩为 170px，保留可操作的时间区域。对象主行桌面高 40px，窄屏高 56px 并将操作按钮放在名称下方，参数 lane 位于对应轨道下方并使用浅灰底表达从属关系。
- 空舞台说明添加素材或空间文字的下一步；时间轴空状态固定居中于标尺下方的可视区域，不随网格滚动或缩放。空状态仍保留标尺、播放和时长控制，不渲染轨道区播放线、结束线和结束遮罩。
- 小程序相机预览以悬浮窗口叠在舞台右上角，保持素材库、工具、检视器和时间轴可用。窗口只保留相机设置与关闭入口，播放统一使用时间轴，9:16 画面随可用空间缩放；打开和关闭不改变主舞台的相机、选择、着色模式或编辑状态。编排与预览共用同一次时间轴播放。
- Gizmos 弹层提供独立的网格和文字标签复选项，修改后保持展开，便于连续调整；问号保留为标签的一键总开关，旁边的小箭头展开 Gizmos 设置；菜单与问号共用同一标签状态。文字标签统一切换左下角“每格 1 米”和场景内的原点、虚拟相机、X/Y/Z 一米文字标签，默认开启；开关仅用于当前编辑会话，不写入场景或撤销历史。网格线、原点坐标轴和相机线框保持各自的原有行为；右上角相机预览始终不绘制编辑辅助标签。
- 舞台明确标出“每格 1 米”，原点带有 1 米长的 X/Y/Z 正向轴。虚拟摄像机设置在独立的紧凑浮岛中提供二维码/地图放置预设、距离、高度、水平角、俯仰角和视场角；打开小程序视角后，在右上角窗口显示 9:16 画面，时间轴仍可拖动和编辑。相机参数只在当前编辑会话内生效，避免与对象属性或演出轨道混淆。

## Elevation & Depth

浮岛使用实色表面与克制阴影区分舞台和操作区域，不使用模糊玻璃。项目栏和时间轴使用轻阴影，左右面板略抬高，原生工具保持较小体量；面板内部仍靠色阶、间距和细边线组织信息。标题栏、检视器和时间轴各有明确层级，浮层挂在工作台主题容器中并继承 Light。

## Shapes

通用控件保留局部主题的 6px 圆角；独立工作面使用 10px 圆角，工具岛使用 8px 圆角，片段维持紧凑圆角和清晰两端把手。这些是场景工作台的局部组合，不修改全站 token 或共享组件。片段两端的调整把手、播放头与结束旗标保持各自形状，避免混淆拖动目标。

## Components

### 素材库与空间文字

- 素材库按“内容类型 → 浏览结果”组织：顶部六类为素材（全部）、模型、图片、视频、音频、文字。媒体只展示团队素材目录，不接收场景引用、使用次数或当前选择。分类定义集中在 `scene-library.ts`，团队目录请求由 `useSceneLibraryCatalog` 管理，文字使用独立面板。
- 媒体搜索词跨类型保留；目录使用服务端搜索与分页。媒体支持网格和列表，音频默认列表，用户选择的布局跨分类保留。卡片显示真实缩略图、类型和可用时长；没有缩略图时显示类型图标，不下载完整视频或模型生成预览。
- “导入”只创建可复用的团队素材，完成后切到对应分类并刷新目录，不新增场景对象。加号或双击可用素材从当前播放头添加；舞台拖放沿用空间落点，时间轴拖放显示插入时间并从落点时间创建新轨道。单击卡片不选择场景内对象；加号、双击或拖放始终添加新实例。
- 文字分类只提供“添加空间文字”入口，已有文字在舞台或时间轴中选择和编辑。文字随场景保存，不创建团队 Asset 或素材引用；复制场景会一并复制内容。收起素材库时，项目栏保留文字快捷入口。
- 素材库不合并场景引用，也不显示使用状态或场景选择高亮；场景内对象统一由舞台与时间轴管理。目录分页按原始返回行推进游标，每次操作最多扫描五页跳过不支持的素材类型；未扫描完时保留加载更多，失败从当前页重试并保留已加载目录。导入进度与错误独立展示。
- 只读、播放中、数量上限、归档或不可用资源通过禁用态和提示反馈；加号提供拖放之外的入口。播放或达到场景容量只限制插入，仍可将文件导入团队库；只读场景不显示导入入口。

### 所选对象检视器

- 顶部为轨道名称与紧凑的素材来源行；下方按空间与外观、文字（仅文字对象）、出入场、媒体播放和类型专属设置分组。各组可折叠，空间音频未启用、模型动画未选择时默认收起。属性内容独立滚动，分组底部保留取消编组；自动化展开、显示、静音、复制和删除只放在轨道头，不在属性面板重复。素材来源可打开原素材；文字直接编辑内容、字号、排版宽度、颜色和对齐。
- 出入场仅编辑出现与消失时间，片段两端与检视器字段编辑同一区间。移除独立淡入、淡出操作，新的视觉渐变通过不透明度关键帧控制，声音渐变通过音量关键帧控制。新实例的旧包络时长始终为零；历史文档已保存的包络保留播放兼容，不在本次 UI 调整中改写。视频的不透明度关键帧不改变音量。
- 音频/视频按素材原速播放，另外提供源起点、源终点、音量和循环；静音在轨道头控制。音量及可见对象的不透明度显示当前播放头采样值。所有加/删关键帧按钮集中在检视器最右列：位置、旋转、缩放分别同时记录 X/Y/Z，不透明度和音量各自记录。实心表示当前点已有完整关键帧，空心高亮表示参数已动画化，部分轴有帧用加粗空心和 mixed 状态表达；点击补齐三轴，再次点击移除当前组的帧。空间音频启用后展开原音距离、衰减边界和衰减强度（距离单位米）；Web 根据虚拟相机的位置试听距离和左右声像，小程序流式播放使用距离衰减。源裁切使用素材内部时间，区别于场景上的出现/消失时间。模型保留内置动画片段、动画起点和循环设置。
- 位置以米、旋转以度显示，保存与采样使用 Euler XYZ 弧度并保留多圈值。未动画化的参数修改静态值，已有轨道的参数在当前播放头写入关键帧。实例可复制或删除；分组提供取消编组及删除，删除分组连同成员一起删除。

### 轨道、片段与关键帧

- 每个模型、图片、音频、视频或文字实例一条轨道，分组是 Track Stack 式父轨道，带展开三角和成员数。轨道顺序就是 `instances` 顺序，分组成员保持连续。轨道与视口选择共用节点 ID，GLB 子网格选取映射回实例根节点。
- 轨道头右侧固定排列自动化、显示、静音、复制和删除；音频/视频才显示静音，音频不显示画面可见开关，分组不提供实例复制。按钮只操作所在轨道，键盘 Delete/Backspace 继续删除所选轨道。复制在原轨道后插入独立副本，保留分组、关键帧、出入场、空间文字和媒体参数并选中新副本；素材引用复用。静音写入同一个 `media.muted`，随场景保存；不会修改音量关键帧。播放中和只读时禁用写操作，达到对象数量上限时禁用复制。按钮点击不会冒泡到原轨道的选择、改名或拖动排序。
- 点击头部或片段选择，⌘/Ctrl 点击加选，Shift 点击连选；双击名称或按 Enter 改名。拖动头部排序，拖到分组头部中段放入分组，上下边缘插到前后；⌘G 编组，⇧⌘G 或检视器“取消编组”把成员上移一层。分组和移动保留静态世界姿态，已有关键帧仍按新父节点的局部值播放；分组数量与嵌套层级不设业务上限，循环引用被拒绝，空分组自动移除。
- 显示开关保存独立的 `hidden`，不覆盖不透明度或关键帧；隐藏对象在选中时也不显示幽灵形态。隐藏分组作用于全部后代，重新显示保留各后代原有的可见设置。视频隐藏只关闭画面，声音由静音和音量控制。隐藏轨道保留在时间轴中，以灰色名称、虚线片段和关闭的眼睛标识，仍可选择编辑。
- 对象主行的片段仅显示出入场区间、边缘把手及适用的循环分界，不重复轨道头部的图标和名称，也不重复文字内容；名称与起止时间保留在悬停提示和无障碍标签中。拖动片段整体平移，拖两端修改出现/消失，默认吸附网格，Alt/Option 精确到毫秒。片段和两端把手支持方向键调整，Shift 放大步长；一次完成的拖动只产生一个撤销步骤，取消拖动不提交。
- 没有出入场设置的历史模型继续用原 GLB 动画起止范围展示片段；移动该历史片段保留原动画起点语义，使用边缘调整后才写入出入场设置。循环 GLB 片段仍标出重复位置。
- 轨道默认收起变换关键帧，在轨道中线用 8px 灰色菱形汇总提示时间点；同一时刻的多个通道合并为一个标记，展开参数后隐藏汇总标记。点曲线按钮或按 A 展开参数 lane：模型、图片和文字显示不透明度及位置/旋转/缩放；视频增加音量；音频只显示有实际效果的音量与位置。分组保留位置/旋转/缩放。变换参数合并 X/Y/Z 关键帧，桌面头部显示当前三轴值的只读摘要；窄屏省略摘要。时间轴头部不再重复放置数值输入和加/删关键帧按钮。部分轴有帧时 lane 上的菱形为空心，拖动合并帧同时移动三个轴，展开可单独编辑各轴。不透明度与音量显示当前百分比和独立关键帧 lane；数值统一在检视器编辑，时间轴保留拖动、删除和曲线插值。
- 检视器右侧菱形按钮添加/移除当前帧，双击 lane 添加，拖动改时，Delete/Backspace 删除选中帧；焦点在轨道头部时删除所选轨道。插值提供线性、缓动、保持；导入的自定义 Bezier 显示“原有曲线”，修改数值或时间不自动改写曲线。
- 标尺刻度与吸附网格随缩放自适应；深色播放头带五边形把手，点击/拖动标尺定位。结束旗标调整场景时长，支持吸附和 Alt/Option 毫秒调整，拖到右缘扩展可视范围。结束后叠加浅灰遮罩，超出时长的关键帧和片段保留；循环开启时显示循环带。Ctrl/⌘ + 滚轮或捏合缩放，工具栏提供缩小、放大、适应全部，播放时视图随播放头翻页。

### 编辑会话、预览与兼容性

- 网格、位置与空间文字尺寸统一为米，不改写已有场景尺度。虚拟摄像机的二维码预设为 `(0, 0, 2)`，地图预设为 `(0, 1.4, 2)`，默认水平朝 -Z，垂直视场角为 60°；地图预设不会自动俯视原点。用户可以调整预览构图，界面说明手机相机视野因设备而异。原点与摄像机辅助器不进入时间轴、文档或小程序播放内容。主舞台保持原来的编辑视角；预览窗口不显示网格、音频标记或用于编辑的幽灵对象，并始终使用素材本身的材质。
- 文档只有一份撤销历史，最多保留 60 个过去快照；标题、素材、文字、出入场、媒体设置、原生变换和关键帧共用历史。Ctrl/⌘ S 保存，Ctrl/⌘ Z 撤销，Shift Z 重做，空格播放/暂停；W/E/R 切换原生变换，F 聚焦。保存冲突保留未保存内容，加载、错误和权限提示沿用同一主题。
- 播放与只读状态禁用内容编辑，预览仍可播放。图标操作提供可访问名称和焦点反馈；减少动态效果偏好会关闭局部过渡。
- 保存仍使用文档 schema 6。没有新能力的历史模型场景保持播放 schema 4（无分组）或 5（有分组）；包含文字、出入场、媒体参数或非模型素材的场景使用 schema 7；不透明度、音量关键帧或空间音频需要 schema 8。schema 7/8 通过 Web 编辑器与配套小程序播放器预览，二维码入口可用于演出场景。旧小程序仍仅支持 4/5，上线时必须配套发布播放器。
- 所有 active 场景使用同一二维码流程。二维码浮层挂到项目栏容器并继承 Light，向内避让边缘，视口点击、Escape 或卸载时关闭并清理监听。
- 每个编辑器持有独立、可销毁的 Scene Core；会话、订阅、RAF 和原生视口随卸载释放。模型模板按 URL 在当前视口引用计数并独立克隆，GLB 包在底部中心对齐的 `pivot` 中，偏移位于 AnimationMixer 驱动子树之外。图片、视频和文字使用空间平面，音频使用仅供编辑的标记；预览隐藏该音频标记。右上角预览共用同一渲染器、模型、纹理、媒体播放器和场景时钟，只增加一次受限区域的相机绘制，不重复加载素材或播放音频。媒体元素和纹理随实例移除、资源替换或卸载释放。

## Do's and Don'ts

- 延续全站语义 token、字体、共享控件和固定 Light；浮岛形态只约束场景工作台。
- 用时间轴表达顺序、层级和时序，用检视器编辑当前选择；保持舞台、轨道和属性的同一选择状态。
- 区分团队可复用素材与场景独有文字，区分场景出入场时间与媒体源裁切时间。
- 保留历史模型片段、关键帧曲线、统一撤销和真实播放协议兼容性。
- 不重复实现 Three 原生变换工具，不开放其独立 JSON、大纲树、任意几何、材质、灯光或脚本入口。

实现以 `SceneEditor`、素材库、对象检视器、`SceneTrack` / `SceneTimeline`、响应式 hooks、媒体表面与播放代码及局部 CSS 为准。`.impeccable/review/desktop.png`、`mobile.png` 和 `scene-validation-20261029/` 中的截图记录此前布局，不代表当前素材面板，也不替代真实媒体与手机播放验收。原生视口来源、MIT 许可、哈希和补丁见 `vendor/three-editor/README.md`；协议、迁移和自动验收见 `docs/scene-asset.md`。
